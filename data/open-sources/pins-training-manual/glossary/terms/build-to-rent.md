# Build to Rent

**Annex B definition** ([NPPF Annex B, p. 103](../../../nppf/NPPF-August-2026.md#AnnexB-build-to-rent)): Build to Rent: Purpose built housing that is typically 100% rented out. It can form part of a wider multi-tenure development comprising either flats or houses, but should be on the same site and/or contiguous with the main development. Schemes will typically be professionally managed stock in single ownership and management control.
