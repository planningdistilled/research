# Large-scale shared living accommodation

**Annex B definition** ([NPPF Annex B, p. 107](../../../nppf/NPPF-August-2026.md#AnnexB-large-scale-shared-living-accommodation)): Large-scale shared living accommodation: Accommodation which provides private rooms alongside shared communal spaces and facilities. This type of accommodation does not constitute self-contained dwellings (use class C3), HMOs, student accommodation, hotels, or other residential institutions.
