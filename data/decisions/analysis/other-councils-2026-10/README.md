# Other councils scored against the four Stratford errors: working papers (18 October 2026)

The merged table is `../other-councils-four-errors-2026-10.tsv` and the note is `../other-councils-four-errors-2026-10.md`; the published comparison is https://planningdistilled.org/research/authority/officer-reports-compared/. This folder holds the working papers behind them:

- `RUBRIC.md`: the shared scoring rubric given to each of the five scoring passes, including the method rules (verbatim quotation with PDF page for every adverse code, text search before any negative).
- `held-a-SUMMARY.md`, `held-b-SUMMARY.md`, `warwick-bromsgrove-SUMMARY.md`, `south-worcs-SUMMARY.md`, `moderngov-SUMMARY.md`: each pass's summary of its set: counts per code, two to four sentences per council with the best verbatim example, and what the set suggests about the Stratford coding.

The officer reports themselves are council copyright and stay in the private sources checkout (`sources:council/` and `sources:council/other-councils-2026-10/`, with each set's `rows.tsv` and the `pdftotext` extracts the page build checks against). The summaries quote them briefly.
